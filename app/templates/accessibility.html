Accessibility and testing

This is a demonstration application created for academic assessment. It is not a production service and it does not claim full Web Content Accessibility Guidelines (WCAG) conformance.

Accessibility approach

The application uses semantic HTML and GOV.UK Frontend components as a foundation. Accessibility is also considered in the way components are combined into complete user journeys.

Recent improvements include clearer form errors, preserved form values after validation errors, visible confirmation before destructive or irreversible actions, contextual labels for repeated actions, semantic navigation and improved table structure.

Testing carried out

The project includes automated tests for selected accessibility-related markup and behaviour. Manual checks should also cover keyboard-only operation, focus order, zoom and reflow, colour contrast and assistive technology.

Known limitations

Automated tests cannot demonstrate that a service is accessible to every user. This prototype has not yet had a formal accessibility audit or usability testing with disabled users. Those activities would be required before making a stronger accessibility claim.

Further work

Future work should include testing with disabled users, broader assistive-technology testing, automated accessibility scanning in the development workflow, continued monitoring of GOV.UK Frontend and WCAG guidance, and a monitored feedback route for an operational service.
